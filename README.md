### Highlights!

**[Cast-it — Personalized AI Podcasts](https://github.com/wenyenhsu/cast-it-podcast-builder)**  
Personalized recommendations for LLM-generated podcasts using RAG-based knowledge retrieval. Built with Django, Docker, PostgreSQL, and Ollama.

**[JägerOS — Career Intelligence Platform](https://github.com/wenyenhsu/jeageros-career-intelligence-platform)**  
A Django-based platform for job tracking, skill extraction with Ollama, market demand analysis, and resume matching.

**[AKB Daily Intelligence](https://github.com/wenyenhsu/llm-powered-daily-intelligence-system)**  
A self-evolving knowledge graph that turns raw information into structured, reusable intelligence through LLM reasoning and embedding-based memory.

**[RoBERTa Sentiment Pipeline](https://github.com/wenyenhsu/llm-roberta-based-sentiment-classification-with-ensemble-approach)**  
An end-to-end RoBERTa ensemble pipeline for social media text, covering collection, preprocessing, training, and evaluation.

**[TPC — Two-Phase Classification](https://github.com/wenyenhsu/classification-method-for-imbalanced-data-using-two-phase-cost-sensitive-svm-and-genetic-algorithm)**  
A classification method for imbalanced data using two-phase cost-sensitive SVM and a genetic algorithm.
